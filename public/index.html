Same repo. Different file. Different context.

An agent never sees your config files — it sees the merged result of every layer that applies to the file it is touching. Pick a target, toggle layers on and off, and watch instructions, settings, permissions, and hooks resolve in precedence order.

Safe educational demo. Nothing is executed and no model is queried — the lab replays the merge logic a real harness performs, with fixtures you can read in examples/.
